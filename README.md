# 族語數位教科書生成平台

教師可從情境圖片與雙語對話出發，編寫包含生詞、語法、閱讀、聽力、口說、寫作與課後小練習的互動課本。

## 開啟編輯平台

https://kenkhw.github.io/unit-language-studio/

不需要 GitHub 帳號即可使用。建議使用 Windows 或 macOS 的新版 Chrome、Edge。

## 教師操作

1. 設定語別、學習目標、情境圖片及雙語對話。
2. 整理生詞與語法，編寫聽說讀寫練習和課後任務。
3. 下載「編輯檔 JSON」保留可修改版本。
4. 下載「互動課本 HTML」提供課堂使用，圖片與音訊會內嵌。
5. 建立新單元前先下載備份；修改舊教材時開啟對應編輯檔。

## 草稿與學生作答

草稿儲存在使用者目前瀏覽器的 IndexedDB，不會上傳 GitHub，也不會跨電腦同步。清除網站資料可能移除草稿，請下載編輯檔備份。學生口說與寫作分別下載作答檔，再交給老師；本平台不會自動回收。

單句與批次語音合成均已開放，下載課本時會補齊缺少的語音。老師也可自己錄音，既有音檔與老師錄音會保留。聽力學生端直接顯示 ABC 與答句文字。翻譯維持原功能，需連網使用原住民族語言研究發展基金會提供的公開服務。錄音需要瀏覽器麥克風權限。已匯出的互動課本可離線瀏覽與播放內嵌音訊。

## 部署

純靜態前端，以 GitHub Pages 發布 main 分支根目錄。沒有後端、私密金鑰或雲端資料庫。`assets/vendor/qrcode-LICENSE.txt` 保留第三方元件授權資訊。
